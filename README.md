## Descripción del Proyecto

Este proyecto consiste en el diseño e implementación de una plataforma de traslados llamada MOVE, con el objetivo de aplicar y evaluar distintos estilos y patrones de arquitectura de software aprendidos durante el curso.

El sistema tiene como objetivo gestionar el ciclo completo de los traslados de bienes dentro de una ciudad, abarcando desde la creación de reservas y la gestión de pagos hasta la asignación de recursos, el monitoreo en tiempo real de los viajes y la detección de situaciones que requieran intervención
